## Overview

A project from Rocketseat's OmniStack Week 11 (2020) that connects NGOs with people willing to help. The goal of the exercise was to build a complete full-stack application, from the database to the interface. It's a study project that cemented my foundation in full-stack JavaScript development.

## Features

- NGO sign-up with a generated login ID.
- NGO login session (SessionController).
- Creating and listing cases (incidents) with title, description and amount.
- NGO profile page listing its cases, with the option to delete them.
- Front-end routes: Logon, Register, Profile and Newincident.

## Technical decisions

- **Layered back end**: `controllers/` splits logic by domain, `routes.js` centralizes routing and `database/` isolates the Knex configuration.
- **SQLite + Knex**: a simple local database with no infrastructure dependency — right for the scope, with migrations handling schema changes.
- **Service layer on the front end** (`src/services`): Axios is kept out of the pages, a pattern that makes maintenance easier.
- **React Router DOM** for navigating between the NGO flows.

## What I learned

- My first full-stack experience: connecting a React front end to my own REST API, from scratch.
- Relational database modeling with Knex (NGOs and cases linked by a foreign key).
- A complete, simple ID-based authentication flow, without external auth libraries.
- Structuring a project with domain-based folders on both the back end and the front end.
