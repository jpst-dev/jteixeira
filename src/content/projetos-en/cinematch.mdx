## Overview

CineMatch is a movie showcase in the style of streaming services. The home page opens with a rotating spotlight of movies in theaters and poster rows (In theaters, Trending, Top rated). Each movie has its own page with everything that helps you decide what to watch.

## Features

- Rotating spotlight that pauses on hover, with a direct link to the trailer.
- Horizontal rows with native scrolling, and full lists with infinite scroll.
- Search with instant suggestions, also opened with the "/" shortcut.
- Explore by genre, year, rating and sort order.
- Movie page with trailer, technical sheet (budget, box office, studios), director, writers, cast, recommendations and where to watch in Brazil.
- Layout designed for phones and large screens, with high-resolution images on 4K.

## Technical decisions

- **Server-side proxy (Vercel Function)**: the TMDb key lives only on the server. The proxy accepts only the paths the app uses, returns 403 for anything else and caches at the edge.
- **Same proxy in development**: a Vite plugin serves the same function locally, so the app behaves the same on my machine and in production.
- **No unnecessary libraries**: `fetch` instead of Axios, and local state with composables instead of Pinia.
- **Vitest tests** for the proxy, formatters and movie-page rules (trailer choice, key crew, technical sheet).
- **Responsive images**: `srcset` lets the browser pick the backdrop size for the screen.

## What I learned

- Protecting API keys in front-end apps with a serverless function instead of shipping them in the bundle.
- Building a cohesive visual identity (colors, type, components) for an existing product.
- Accessibility in interactive components: a full-screen menu with a focus trap, a keyboard shortcut and keyboard navigation in the spotlight.
