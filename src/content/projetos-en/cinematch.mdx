## Overview

CineMatch is a movie recommendation project that pairs good looks with real functionality, consuming an external API. Users can discover popular or top-rated movies, or filter by genre, rating and release date — all in a fast, responsive interface.

## Features

- Suggestions by popularity and rating.
- Debounced search with instant suggestions (autocomplete).
- Filters by genre, rating, popularity and date.
- Movie cards in 3 customizable sizes.
- Infinite scroll for dynamic loading.
- Carousels with now-playing and recommended movies.
- Full details: synopsis, trailer, cast and where to watch.
- Responsive layout for every screen size.

## Technical decisions

- **Vue 3 + TypeScript (Vite)**: a modern base with strong typing across all the data coming from the API.
- **Pinia** for global state, keeping filters and data predictable.
- **Debounced search with VueUse**: avoids firing a request on every keystroke, cutting cost and latency.
- **Infinite scroll + carousels**: dynamic loading without explicit pagination, prioritizing smooth browsing.
- **Axios** for HTTP requests to TMDb, with the API layer isolated from the rest of the app.

## What I learned

- Real-world integration with an external API (TMDb): key-based auth, response handling and typed data.
- UX patterns like autocomplete, debouncing and incremental loading.
- Deploying an SPA on Vercel with environment variables (`VITE_TMDB_API_KEY`).

> Note: since this is a static SPA, the TMDb key ships in the client bundle (the service's standard approach for read-only apps). A natural next step is moving API calls behind a server-side proxy, as I did in DealsGamer.
