## Overview

A PC game deal tracker that brings prices and sales from many stores into a single interface, using data from [IsThereAnyDeal](https://docs.isthereanydeal.com/). The goal is a great user experience while keeping API usage low and predictable.

## Features

- Storefront-style home: a hero with Steam artwork and themed shelves.
- `/ofertas` catalog with always-visible filters (a side panel on mobile), applied instantly with state in the URL, plus collections like `/ofertas/gratis` (free) and `/ofertas/acabando` (ending soon).
- Incremental loading with auto-load plus a manual "Load more" button.
- Global search with suggestions that already show cover art, price, discount and historical low; recent searches and `/` and `Ctrl+K` shortcuts.
- Game page with a buy box, stores sorted by price and a visual price history.
- Slug-based URLs (`/game/cyberpunk-2077`).
- Favorites at `/favoritos` with the current best price, saved in the browser.
- SEO: per-page meta, product JSON-LD, canonical URLs, sitemap and robots.

## Technical decisions and architecture

- **SSR with Nuxt 3**: better SEO (key for indexing a catalog) and faster first load.
- **Server API routes** (Nitro, `server/api/**`): the IsThereAnyDeal key lives only on the server, out of the client bundle, and data normalization happens in one place.
- **SWR caching on the routes**: responses are reused across visitors, keeping API usage low and predictable.
- **Strict TypeScript** throughout, making the integration with external data more reliable.
- **Centralized normalization** in the `useGamesApi.ts` composable, keeping pages decoupled from the API's shape.
- **Global state with Pinia** (`stores/games.ts`) for favorites and filters, with no server-side storage.
- **Price chart with Chart.js + vue-chartjs** on the game page.
- **Yarn 4** with the `node_modules` linker for faster, reproducible installs.

## What I learned

- How to design an API proxy that protects credentials in SSR apps.
- Incremental loading and autocomplete patterns that keep request costs low.
- Continuous deployment on Vercel with environment variables for Production/Preview/Development.
