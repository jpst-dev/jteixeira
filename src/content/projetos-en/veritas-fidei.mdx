## Overview

Veritas Fidei is a site for Catholics who want to understand what the Church teaches, why, and where it is found in Scripture and Tradition. Content is split into **Learn** (teaching articles), **Tracks** (articles in order on one subject) and **Defending the faith** (answers to objections).

## Features

- Teaching and apologetics articles, organized into topics and study tracks.
- Apologetics articles in the medieval disputed-question format: "It seems that…", "On the contrary…" and "I answer that".
- Table of contents, reading progress bar and reading time computed at build time.
- Accent color that changes with the liturgical season (green, purple, white and gold, red).
- Dark theme by default, with a light mode saved in the browser.
- RSS feed generated at build time.

## Technical decisions

- **Restart instead of patching**: a content site's value is in being found and shared, and an SPA ships empty HTML. With static generation every page is ready for Google and for link previews.
- **Nuxt Content with a schema**: each article's title, topic, status and references are validated at build time; publishing means adding a `.md` file.
- **Review as code**: `npm run verificar` checks structure, Catechism citations, reference links and spelling (LanguageTool). Drafts only show in development, with a status badge.
- **Computed liturgical calendar**: the season comes from the Roman calendar with the transfers used in Brazil, covered by tests.
- **Typography for long reading**: Literata for body text and Cinzel for headings, and references like "CIC 1252" never break across lines.

## What I learned

- Choosing the architecture by product type: content calls for static rendering, not an SPA.
- Treating content as code, with a schema, validation and automated review.
- Building a visual identity that reinforces the site's subject.
