## Overview

An interactive, educational platform for studying and defending the Catholic faith, focused on well-organized content and a good browsing experience.

## Features

- Content in a Categories → Subcategories → Topics hierarchy, with a dedicated page for each level.
- Topic detail page with related tags.
- Improved search bar and a results page.
- Favorites persisted locally with Pinia.
- Light/dark theme with Pinia.
- Breadcrumbs for deep navigation.
- About page with mission cards, responsive layout and a custom 404 page.
- MIT license.

## Structure and technical decisions

- **One view per hierarchy level**: `HomeView`, `CategoriesView`, `CategoryView`, `SubcategoryView`, `TopicsView`, `TopicView`, `TagView` and `SearchView` — each level has its own route and component, keeping the code simple and navigation predictable.
- **Components organized by domain**: `category/`, `topic/` and `common/` folders separate feature-specific components from reusable ones (Navbar, Footer, Breadcrumbs, TopicCard, TagList).
- **Pinia for global state**: `favorites` and `theme` stores, decoupled from the view layer.
- **Vue Router** with clean, hierarchical routes.

## What I learned

- Modeling routes and components for hierarchical content (categories → subcategories → topics).
- Practical use of Pinia in a real app: theme and favorites state.
- Organizing components by domain in a mid-sized Vue project, with maintainability in mind.
