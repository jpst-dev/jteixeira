## Visão geral

Comparador de ofertas de jogos para PC que consolida preços e promoções de diversas lojas em uma interface única, usando dados da [IsThereAnyDeal](https://docs.isthereanydeal.com/). O foco do MVP é entregar boa experiência de usuário mantendo o consumo da API baixo e previsível.

## Funcionalidades do MVP

- Home com ofertas em destaque, ordenação e filtros avançados.
- Carregamento incremental com auto-load + botão manual "Carregar mais".
- Busca global com autocomplete (dropdown) e navegação direta para a página de detalhe.
- Página de detalhe com metadados, tabela de preços e histórico visual.
- URL amigável por slug (`/game/cyberpunk-2077`).
- Favoritos e filtros locais via Pinia.

## Decisões técnicas e arquitetura

- **SSR com Nuxt 3**: melhora SEO (importante para indexação de catálogo) e performance de primeiro carregamento.
- **Proxy de API no servidor** (`server/api/itad-proxy.ts`): a chave da IsThereAnyDeal fica apenas no servidor, evitando exposição no bundle do client e centralizando a lógica de normalização dos dados.
- **TypeScript strict** em todo o código, reforçando a confiabilidade da integração com dados externos.
- **Normalização centralizada** no composable `useGamesApi.ts`, mantendo páginas desacopladas do formato da API.
- **Estado global via Pinia** (`stores/games.ts`) para favoritos e filtros, sem dependência de armazenamento server-side.
- **Grafo de preços com Chart.js + vue-chartjs** na página de detalhe.
- **Yarn 4** com `node_modules` linker para instalação mais rápida e reprodutível.

Estrutura principal: `app.vue` (shell com header/busca/footer), `pages/index.vue` (catálogo), `pages/search/index.vue` (resultados), `pages/game/[id].vue` (detalhe), `server/api/itad-proxy.ts` (proxy), `stores/games.ts` (estado).
