## Visão geral

Projeto da Semana OmniStack 11 (Rocketseat, 2020), que conecta ONGs a pessoas dispostas a ajudar. O foco do exercício foi construir uma aplicação full-stack completa, do banco de dados à interface. É um projeto de estudo que consolidou a base do desenvolvimento web full-stack com JavaScript.

## Funcionalidades

- Cadastro de ONGs com geração de ID para login.
- Sessão de login da ONG (SessionController).
- Cadastro e listagem de casos (incidentes) com título, descrição e valor.
- Página de perfil da ONG listando seus casos, com opção de exclusão.
- Frontend com rotas: Logon, Register, Profile e Newincident.

## Decisões técnicas

- **Backend organizado em camadas**: `controllers/` separa a lógica por domínio, `routes.js` centraliza as rotas e `database/` isola a configuração do Knex.
- **SQLite + Knex**: banco local simples e sem dependência de infraestrutura — adequado para o escopo, com migrations garantindo a evolução do schema.
- **Camada de serviços no frontend** (`src/services`): o Axios fica isolado das páginas, padrão que facilita manutenção.
- **React Router DOM** para navegação entre os fluxos da ONG.

## Aprendizados

- Primeira experiência full-stack: conectar frontend React a uma API REST própria, do zero.
- Modelagem de banco relacional com Knex (ONGs e casos com chave estrangeira).
- Fluxo completo de autenticação simples baseada em ID, sem bibliotecas externas de auth.
- Estruturação de projeto com pastas por domínio, tanto no backend quanto no frontend.

> Projeto de estudo: escrito em JavaScript (sem TypeScript) e sem deploy publicado. Mantido aqui como registro da minha primeira aplicação full stack de ponta a ponta.
